pysdkit.data
============

Synthetic generators and packaged demo arrays.

``.npy`` assets ship under ``pysdkit/data/real_world`` and are resolved
by name (for example ``load_bmemd_source02()``).  Text assets such as
``texture.txt`` remain at the package root.  Do not load demo data from
the local ``repo/`` tree.
