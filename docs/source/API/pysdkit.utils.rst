pysdkit.utils
=============

Shared numerical utilities (FFT, Hilbert, smoothing, deconvolution,
blind source separation).

Import :class:`~pysdkit.utils.BSS` from here.  The functional alias
``bss`` lives in :mod:`pysdkit.utils.bss` only, so it does not shadow
the subpackage name.
