About
=====

PySDKit collects **signal decomposition** algorithms in one Python
package so they can be used as feature-engineering tools next to NumPy,
SciPy, and machine-learning stacks.

It is not a linear subspace-identification toolbox (state-space
``A, B, C, D`` from IO data).  The public API is mode extraction:
EMD-style sifting, variational / chirp models, image decompositions,
and related time-frequency transforms.

- GitHub: https://github.com/wwhenxuan/PySDKit
- PyPI: https://pypi.org/project/PySDKit/
- Docs: https://pysdkit.readthedocs.io/

Please cite the original papers of each algorithm you use; class and
module docstrings point to those references.

If you want to add an algorithm, tests, or a gallery example, see
:doc:`../development/index`.
